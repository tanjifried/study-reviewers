PYTHON EXAM REVIEWER

Open index.html in a modern browser. The reviewer works without an internet connection; external Python documentation links require internet access. Start with a lesson, then take a 10-question practice quiz. Each lesson includes expanded explanations, worked examples, links to relevant W3Schools tutorials and official Python documentation, and the supplied exam objectives PDF.

The final exam lets you choose 1 to 302 questions across the six areas (default 40), with an optional 50-minute timer. The 80% target is a personal study target, not an official passing score. Feedback appears after every lesson question. Final exam feedback appears after submission by default, with an option to check each answer immediately. Multi-part questions receive partial credit. Missed-question practice is available after completing an attempt. New attempts prioritize questions seen less often, while selecting across objectives. Progress and final setup preferences are stored locally in your browser; different browsers or devices have separate progress. Active attempts are not resumed if you leave the page.

sample-images/ contains the 116 images extracted from the linked sample document. They feature Java practice questions and were used as a style reference. The Python questions here are original practice material and are not official Pearson exam questions. The files in data/ contain the lesson and question bank.

MOCK EXAM (added 2026-11-19)
- Mock exam (#mock): 30 questions recreated from 40 photos of a Pearson-style mock exam . Duplicate photos were merged into one question each. Questions 7, 15, 27, 33 and 34 were never photographed. Answers can be checked one at a time (default) or after submitting.
- Some drop-down lists and code lines were never visible in any photo. Their options were reconstructed with exam-style choices and are labelled "Reconstructed" on each slide.
- Mock-exam lesson (#mock-lesson): one slide per question with the original photo, the solved question, a step-by-step justification and an exam tip. Use the arrow keys to move between slides. Click a photo to open it at full size.
- Cheat sheet (#cheatsheet): syntax to remember plus mistakes to avoid. It can be printed or saved as a PDF.
- All lesson question banks were rewritten in the mock exam's formats: drag-and-drop matching, True/False grids, drop-down code completion, "Choose 2", typed integer answers, and outcome-style multiple choice. Every answer was checked by running the code in Python.
- Data: data/mock.js. Resized photos: mock-images/.
