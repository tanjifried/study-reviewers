PYTHON EXAM REVIEWER

Open index.html in a modern browser. The reviewer works without an internet connection; external Python documentation links require internet access. Start with a lesson, then take a 10-question practice quiz. Each lesson includes expanded explanations, worked examples, links to relevant W3Schools tutorials and official Python documentation, and the supplied exam objectives PDF.

The final exam selects 40 questions across the six areas, and has an optional 50-minute timer. The 80% target is a personal study target, not an official passing score. Feedback appears after every lesson question. Final exam feedback appears after submission by default, with an option to check each answer immediately. Multi-part questions receive partial credit. Missed-question practice is available after completing an attempt. New attempts prioritize questions seen less often, while selecting across objectives. Progress is stored locally in your browser; different browsers or devices have separate progress. Active attempts are not resumed if you leave the page.

sample-images/ contains the 116 images extracted from the linked sample document. They feature Java practice questions and were used as a style reference. The Python questions here are original practice material and are not official Pearson exam questions. The files in data/ contain the lesson and question bank.
